# 2026.296.1819 — fix(kind): the skill frontmatter parses again

## Summary

`#10` put a bare apostrophe (`kind's`) inside the skill's single-quoted YAML `description:` scalar. A single-quoted scalar must double an apostrophe (`''`), so the scalar terminated early and the frontmatter no longer parsed. `charly marketplace generate` aborted projecting this repo:

```
charly marketplace: skill "kind": parse frontmatter of .../layer-kind@v2026.296.1731/.agents/skills/kind/SKILL.md: yaml: line 5: did not find expected key
```

The sentence is reworded to carry no bare apostrophe (`mapped to the provider word kind expects via KIND_EXPERIMENTAL_PROVIDER`). One line; no other change.

Diff: `1 file changed, 1 insertion(+), 1 deletion(-)`; head `d91873bea9892e9bfc50ba56f2aa3492c0d4a5b2`, tree `3e0ec8fd6e4dc5fa1f5cc5c98cd7ec04ac11db50`.
